**SKA Design is Sinera's free, open-source library of 4,278 website templates and 2,417 UI components.** Explore HTML, CSS, JavaScript, and Tailwind CSS templates alongside React projects for SaaS landing pages, e-commerce stores, creative portfolios, agency websites, and business services.

SKA brings complete page designs and individual interface elements into one library, organized by industry and component type. Use it to find web design inspiration, prototype a new site, customize a landing page, or copy a section into an existing frontend project. The collection includes source code, preview images, template metadata, and website design notes.

For developers, designers, and teams building a frontend, the library provides examples from the full page down to a single hero, pricing table, form, or navigation menu. Browse 17 website categories and 21 component categories, compare designs through their preview images, and use the included design notes and six design-system themes to guide customization.

Browse the folders below, explore the [SKA library website](https://ska.sinera.io/), or clone the repository to download the free template collection. No SKA account or subscription is required to access the source on GitHub. SKA Design is a project by [Sinera](https://sinera.io/).

## Getting started

### Download the template library

```bash
git clone https://github.com/Archiver-KA/SKA-Design.git
cd SKA-Design
```

Choose a category in [website templates](templates/websites) or [UI components](templates/components), then open the template folder you want to use. Each template is a separate example; there is no shared application to install at the repository root.

### Preview an HTML website template

Open the template's `index.html` in a browser. Templates that require an HTTP server should be served from their own folder. Many examples use CDN-hosted Tailwind CSS, fonts, icons, or scripts, so an internet connection may be needed for the full design to load.

Website folders include a `DESIGN.md` with design notes and a `banner.webp` preview. Use these to explore the template's colors, typography, spacing, and page structure before customizing the source.

### Run a React template

For a template containing `package.json` and React source files, open a terminal inside that template's folder and run:

```bash
npm install
npm run dev
```

Check its `package.json` for available scripts and dependencies. React/Vite templates need their development server or build process rather than opening the source `index.html` directly.

### Reuse a UI component

Open a component's `index.html` to preview it. Where `component.html` is present, use that file as the section or widget to copy into your page. Bring over the styles, scripts, images, and dependencies it uses, then adapt the content to your project.
